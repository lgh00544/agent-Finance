# 游资批次3 · 补东财三日榜（3d 口径）

## 目标
补上龙虎榜 **3d 口径（三日累计榜）**。当前消费侧已支持 3d（`hot_money.py` 有 `lhb_3d_net_buy` + `verify_net_buy(lhb_type="3d")`）、落库已透传 lhb_type，**唯独抓取侧只产生当日榜**，3d 查询恒空。本批只补抓取侧，让三日榜数据落地。

## 背景（已核实）

- `_fetch_em_stocks()` 东财直连当日榜，`out["lhb_type"]="1d"` 固定
- `_fetch_em_seats()` 席位明细，东财 `flag='1'` 当日；东财接口本身支持 `flag='3'` 三日累计（代码注释已写明）
- `fetch_lhb_seats()` L296 `if lhb_type != "1d": return empty` → 3d 直接空
- `fetch_lhb_stocks()` 无 lhb_type 参数，固定字面值 "1d"
- 消费侧 hot_money.py（`lhb_3d_net_buy`、`verify_net_buy(lhb_type)`) 和 repo.insert_lhb_flows/list_lhb_flows 均支持 3d，零改动

## 改动点（全部在 backend/app/datasource/dragon_tiger_source.py）

| 位置 | 改动 | 备注 |
|---|---|---|
| `_fetch_em_stocks()` | 加 `lhb_type="1d"` 参数（默认 1d），三日榜传 "3d" 用东财三日 flag/接口 | 东财 `DAILYBILLBOARD` 三日口径真实可拉；不可靠则诚实降级返回空，勿伪造 |
| `_fetch_em_seats()` | 加 `lhb_type` 参数，三日榜过滤 `flag='3'`（三日累计席位） | 沿用现有 vendored 直连 JSON 容错解析 |
| `fetch_lhb_seats()` | 放开 `lhb_type != "1d"` 的早退，透传 3d 给 `_fetch_em_seats` | 3d 与 1d 同源分别落库 |
| `fetch_lhb_stocks()` | 加 `lhb_type` 参数透传，去固定字面值 | 支持 3d 股票级净买 |
| `fetch_and_merge()` / `fetch_dragon_tiger()` | 增加对 3d 的抓取/落库分支 | 与 1d 同结构落库，lhb_type 标 "3d" |

## 红线
1. 只改 `backend/app/datasource/dragon_tiger_source.py`；禁动 hot_money.py / routes / 前端 / types
2. 不引新依赖；复用已有 vendored 直连 + 缓存 + 容错解析
3. 三日榜数据不可靠时**诚实降级**返回空，不伪造金额 / 不拿 1d 冒充 3d
4. 消费侧 3d 字段已存在，不改其语义
