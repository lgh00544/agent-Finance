# AlertsPage 消息列结构化 + 完整日志可折叠

## 目标

`D:\self\web\src\pages\AlertsPage.tsx` 单文件改两件事：① 完整日志卡片右上角同时有「展开」和「收起」切换；② 消息列按字段分行展示（不再死挤一坨文字）。

## 改动点

| 位置 | 改动 | 备注 |
|---|---|---|
| 完整日志 Card extra（L128） | 在「展开完整日志」按钮旁加条件渲染：「logOpen ? 收起」显示按钮，否则显示「展开完整日志」 | 两个按钮走同一个 setLogOpen 切换 |
| cols 数组「消息」列（L65） | render 改为：把 message 按 ； 分段，每段一行展示；前置字段名（现价/涨幅/均线/MACD/形态/支撑位/建议）解析；用 Space direction="vertical" size={2} 排版 | 字段名若在消息里出现就用 span 高亮，否则原样 |
| 整体表格宽度 | 「消息」列 width 不限制（去掉 ellipsis），让结构化字段占满 | 列表会变高但更易读 |

## 消息解析规则

按中文 ；/，分句 → 检测关键字分组：

| 检测关键字 | 字段名 |
|---|---|
| `现价` / `涨` / `跌` | 现价 / 涨跌幅 |
| `MA5` / `MA10` / `MA20` / `均线` | 均线 |
| `MACD` / `DIF` / `DEA` | MACD |
| `RSI` / `KDJ` / `BOLL` | 技术指标 |
| `支撑位` / `压力位` / `止损` / `止盈` | 关键位 |
| `建议` / `触发` / `关注` | 建议 |

不命中的就原句保留。

## 红线

1. 不动后端 / API 层 / 类型定义（消息模板在后端，前端只解析）
2. 不引入新依赖
3. 资金告警 / 任务状态两段不变
4. 关键字过滤逻辑不变
5. 完整日志默认折叠（logOpen=false）
6. 消息列结构化后类型行内字段若为空（message 为 null），显示 '—'
7. 不弹 toast / modal
