# 新机器部署指南（零门槛 · 照着抄就能跑）

> 适用：在**另一台电脑**上把本项目跑起来（Windows 11 示例）。
> 全程约 15~30 分钟，所有命令直接复制粘贴即可。
> 遇到任何一步看不懂或报错，先看文末「常见问题」；再不行按报错原文问我。

## 2. 一键准备环境（推荐，或手动执行 2.1~2.3）

在项目根目录**双击运行** `setup_new_machine.bat`：
- 自动创建虚拟环境 `.venv`
- 自动安装全部依赖（首次约 5~10 分钟）
- 没有 `.env` 时自动从模板生成
- 最后打印两条启动命令

> 如果双击报错或想手动来，按下面 2.1 ~ 2.3 执行，效果相同。

### 2.1 创建虚拟环境
```bash
python -m venv .venv
```

### 2.2 安装依赖（两条都要装）
```bash
.venv\Scripts\pip install -r backend\requirements.txt
.venv\Scripts\pip install -r streamlit\requirements.txt
```

### 2.3 生成并填写 .env
```bash
copy .env.example .env
notepad .env
```
在打开的 .env 里只改这几行（其余保持默认）：

```ini
# 必填：DeepSeek（没有它整个系统不会说话）
DEEPSEEK_API_KEY=sk-你的key

# 建议填：SiliconFlow 的 embedding key（bge-m3 免费额度）
# 填了 = embedding 走云端，什么都不用下载
# 不填 = 必须走本地模型，请看第 3 步「embedding 二选一」
SILICONFLOW_API_KEY=sk-你的key

# 想要「游资追踪」页有真实龙虎榜数据就改成 true
DRAGON_TIGER_ENABLE=true
```

## 3. embedding 二选一（⚠️ 最容易踩坑的一步）

系统需要 embedding（向量化）能力，两种方式任选其一：

- **方式 1（推荐）**：第 2.3 步填了有效的 `SILICONFLOW_API_KEY` → **什么都不用做**，默认配置即生效。
- **方式 2**：没有 SiliconFlow key → 用本地模型，**必须手动下载一次**（约 95MB）：
  1. 在 `.env` 里改两行：
     ```ini
     EMBEDDING_PROVIDER=local
     LOCAL_EMBEDDING_MODEL=D:\space\self\self\data\models\bge-small-zh-v1.5
     ```
     （把路径换成你实际的 `agent-Finance` 目录）
  2. 运行下面命令把模型下载到本地（国内网络可用，从 ModelScope 拉取）：
     ```bash
     .venv\Scripts\python - <<'EOF'
     import pathlib, urllib.request
     base = "https://modelscope.cn/models/AI-ModelScope/bge-small-zh-v1.5/resolve/master/"
     target = pathlib.Path(r"D:\space\self\self\data\models\bge-small-zh-v1.5")
     (target / "1_Pooling").mkdir(parents=True, exist_ok=True)
     for f in ["config.json", "config_sentence_transformers.json", "modules.json",
               "sentence_bert_config.json", "special_tokens_map.json", "tokenizer.json",
               "tokenizer_config.json", "vocab.txt", "1_Pooling/config.json",
               "model.safetensors"]:
         dest = target / f
         if dest.exists() and dest.stat().st_size > 1000:
             print("skip", f); continue
         req = urllib.request.Request(base + f, headers={"User-Agent": "Mozilla/5.0"})
         with urllib.request.urlopen(req, timeout=600) as r, open(dest, "wb") as out:
             while True:
                 chunk = r.read(1 << 20)
                 if not chunk: break
                 out.write(chunk)
         print("done", f)
     print("模型下载完成")
     EOF
     ```

> 怎么判断踩坑了：启动后跑评分/候选一直卡住不动，后端日志刷 `huggingface.co ... Retrying` —— 就是 embedding 没配好，回来看本节。

## 4. 启动系统（两个终端）

**终端 1 —— 后端 API（先起这个）**
```bash
cd backend
set PYTHONPATH=你的项目根目录;你的项目根目录\backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```
> 例：项目在 `D:\agent-Finance`，则 `set PYTHONPATH=D:\agent-Finance;D:\agent-Finance\backend`
> ⚠️ 这行不能省！不设会报 `No module named 'agent_prompts'`。

**终端 2 —— 面板**
```bash
cd 你的项目根目录
.venv\Scripts\python.exe -m streamlit run streamlit\app.py --server.port 8501
```

**验证**：
- 浏览器打开 http://localhost:8501 → 看到「系统概览」页即成功
- 后端健康检查：浏览器打开 http://127.0.0.1:8000/api/health → 返回 `{"status":"ok"...}` 即成功

## 5. 想有真实龙虎榜/游资数据（可选，一次即可）

确保 `.env` 里 `DRAGON_TIGER_ENABLE=true`，然后：
```bash
.venv\Scripts\python backend\scripts\fetch_dragon_tiger.py
```

- 自动抓**最近一个交易日**的龙虎榜并落库（T+1 语义，收盘后跑才有当天数据）

- 抓完打开面板「游资追踪」页即可看到档案/龙虎榜/席位监控/留痕
- 之后每天 16:30 后端会自动抓，无需手动

## 7. 常见问题（FAQ）

| 现象 | 原因与解决 |
|---|---|
| `'python' 不是内部或外部命令` | Python 没装或没勾 PATH → 重装 Python 时勾选 Add python.exe to PATH |
| 后端启动报 `No module named 'agent_prompts'` | 第 4 步的 `set PYTHONPATH=...` 没执行或路径不对 |
| 面板打开报「后端服务连接失败」 | 后端没起，或端口被占 → 先起后端；`netstat -ano \| findstr 8000` 查占用 |
| 评分/候选一直转圈，日志刷 `huggingface.co Retrying` | embedding 没配好 → 回第 3 步（填 SiliconFlow key 或下载本地模型） |
| 日志报 `Token is invalid` (401) | 对应 API key 填错/过期 → 检查 .env 里的 key |
| 抓龙虎榜打印乱码 | 正常，Windows 控制台编码问题，不影响数据 |
| `git push` 要密码 | 用 HTTPS+Token 方式（第 1 步方式 A），密码处粘 Token |
| 页面报「数据置信度不足…仅参考」 | 正常！单源数据诚实降级（K227），不是故障 |

## 8. 想连原有数据一起搬？（可选，最省事）

本机的 `data/` 目录包含：dev.db（数据库，含真实龙虎榜数据）、qdrant_storage（向量库）、
models（本地 embedding 模型）。把它整个复制到新机器项目根目录即可：
- 不需要第 3 步下载模型（models 已含）
- 不需要第 5 步抓龙虎榜（数据已在）
- 注意：dev.db 里也包含本机的持仓/交易/复盘记录，属于个人隐私数据，复制前确认
