## 字段 Schema

### `/api/portfolio/daily-summary?days=30`
```json
{
  "days": 30,
  "current": { "date": "2026-08-25", "pnl_pct": 0.97, "pnl_amount": 12340, "market_value": 1234567 },
  "series": [{"date": "...", "pnl_pct": 0.5}, ...],  // 30 日曲线
  "top_gainers": [{"code": "...", "name": "...", "pnl_pct": 6.7}, ...],  // top 3
  "top_losers": [{"code": "...", "name": "...", "pnl_pct": -2.1}, ...],  // top 3
  "summary_text": "今日组合 +0.97%，近 30 日 +3.2%，跑赢沪深 300 +1.8%..."
}
```

### `/api/track/verify/list?start_date=&end_date=&rating=&status=&limit=200`
```json
[{"select_date": "...", "stock_code": "...", "rating": "A", "status": "verified", "pnl_pct_5d": 4.2}, ...]
```
**兼容旧 select_date 单参**（start_date 缺省 = end_date = select_date）。

### `/api/kline/{code}?start=YYYY-MM-DD&end=YYYY-MM-DD`
```json
{"code": "000725", "klines": [{"date": "...", "open": 4.2, "high": 4.3, "low": 4.1, "close": 4.25, "volume": 12345678}, ...]}
```
