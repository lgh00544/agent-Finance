### 场景 5：游资胜率统计（K189 实战验证）

**统计维度**：
```
游资 A 历史操作 100 次
  ↓
盈利次数 / 总次数 = 胜率
  ↓
平均盈利 / 平均亏损 = 盈亏比
  ↓
胜率 ≥ 60% + 盈亏比 ≥ 2 = 优质游资
胜率 40-60% = 普通游资
胜率 < 40% = 警惕游资
```

**实战应用**：
- 优质游资 = 跟买优先级高
- 警惕游资 = 跟买警惕 / 反向指标

## 八、K227 字段误读防御（必查）

**游资数据容易误读的 5 大字段**：

```
1. 累计涨幅 ≠ 估值字段
   - 错误：把动态 PE 14.11 当成 5 日累计 +14.11%
   - 正确：5 日累计 = (现价 - 5 日前收盘) / 5 日前收盘

2. 52 周高低 ≠ 涨跌停价
   - 错误：把当日涨停价 21.11 当成 52 周高
   - 正确：52 周高 = 过去 52 周最高收盘价

3. 盘中瞬时 ≠ 收盘全口径
   - 错误：把 14:00 主力净额当成全日
   - 正确：全日主力净额 = 收盘后龙虎榜

4. 游资净买入 ≠ 主力意图
   - 错误：游资净买入 1 亿 = 主力看多
   - 正确：游资 ≠ 全部主力（K226 9 大主体）

5. 单源数据 ≠ 多源验证
   - 错误：只用同花顺 1 个数据源
   - 正确：龙虎榜 + 同花顺 + 东方财富 + 新浪（4 源）
```
