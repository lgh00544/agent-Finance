## 0. 写在最前：核心哲学

**一句话：只做"主力吸筹结束、即将拉升"那一刻的票。其他阶段全部不碰。**

具体拒绝清单：
- ❌ 拉升期高位（已经在涨的）→ 容易接到最后一棒
- ❌ 派发期（主力在卖货）→ 必亏
- ❌ 下跌期（趋势向下）→ 容易抄在半山腰
- ✅ **吸筹末期（LPS 出现后）= 唯一进场点**

**为什么这样选？**
因为拉升期初段是 5 个阶段里**风险收益比最高**的窗口：
- 下方有吸筹区支撑（止损位明确）
- 主力成本已知（吸筹区中位）
- 主力没有出货动机（还没赚够）
- 距离上方派发区还有 1-2 倍空间

**派发期 = 一票否决**：任何技术分析、任何利好消息，只要主力已经在派发，立即排除，不与其他信号平级加权（亨通惨案教训：310 亿订单 + AI 龙头光环 = 主力借利好出货）。

### 0.1 重要原则（必读）

> **所有框架/工具/红线/口诀 = 参考权重，不是死条件。**
> **市况是上下文，个股是特例。**
> **实战中必须根据当下情况灵活调整。**

- ❌ 不要写死"沪指 < 4000 = 0 新建仓"（这是动态参考线）
- ❌ 不要写死"高位放量 = 派发"（牛市健康突破 vs 熊市派发）
- ❌ 不要把任何口诀当绝对真理
- ✅ 所有信号都要结合市况 + 政策 + 板块 + 个股阶段综合判断
- ✅ K22 工具不是枷锁（用户钦定红线）⭐

## 1. 选股漏斗（5 层过滤）

```
[Layer 1] 市况过滤（7 维动态综合） → 沪指只是参考之一
       ↓
[Layer 2] 板块过滤              → 主流资金流入板块
       ↓
[Layer 3] K8 v2 6 项硬检查       → 1 项不过 = 重要参考（可结合市况适度放宽）
       ↓
[Layer 4] 5 维评分（V4.3 v2）    → 评分 < 4.0 = 排除
       ↓
[Layer 5] K16 11 项失效         → 警 ≥ 5 项 = 排除
       ↓
[Layer 6] 派发期一票否决          → 派发期 = 排除（最高优先级，唯一绝对）
       ↓
[Layer 7] K168 三维验证          → 3 维矛盾 = 警惕
       ↓
[Output] 决策：候选 / 观察 / 排除
```

**漏斗关键原则**：
- Layer 1-5 = 参考权重（可结合市况调整）
- Layer 6 派发期 = **唯一绝对条件**（一票否决）
- 前面 3 层任何 1 层不通过 = 重要警示，不一定要立即排除，但要大幅降权

## 2. Layer 1：市况判断（动态参考，不是死条件）

### 2.1 核心理念

> **沪指 4000 红线 = 动态参考线，不是硬性一票否决。**
> **任何框架/工具/红线 = 都是参考权重，不是绝对条件。**
> **实战中必须根据当下市况、政策环境、量能配合、板块热度综合判断。**

**为什么不是死条件？**
- 沪指 < 4000 时，可能有强政策驱动（如国家级利好）= 可以建仓
- 沪指 > 4000 时，可能是高位滞涨 + 派发期 = 反而要减仓
- 沪指 3800 但创业板强 + 板块集中 = 仍然有结构性机会
- **市况判断 = 多维综合，不是单数字决定**

### 2.2 数据源
- 沪指实时：`qt.gtimg.cn` 字段 `sh000001`
- 创业板实时：`sz399006`
- 沪深 300：`sh000300`
- 北向资金：东方财富
- 板块资金流：东方财富 / 同花顺

### 2.3 市况多维综合判定（7 维度）

**不靠单一数字 = 多维交叉印证：**

| 维度 | 数据 | 判定信号 |
|---|---|---|
| 沪指位置 | 实时点数 | 在 30 日区间分位 |
| 沪指趋势 | 5 日/10 日方向 | 上涨/下跌/震荡 |
| 创业板强弱 | 创业板 vs 沪指 | 资金进成长还是避险 |
| 北向资金 | 净流入/流出 | 外资态度 |
| 板块联动 | TOP3 板块资金流 | 主力方向 |
| 政策环境 | 国家级/行业级 | 政策驱动 vs 无政策 |
| 量能配合 | 今日/30 日均量 | 放量/缩量 |

**综合判定 5 档**（结合 7 维 + 政策 + 板块）：

| 沪指 + 政策 + 板块 | 市况 | 仓位建议 | 选股策略 |
|---|---|---|---|
| 沪指 ≥ 4000 + 政策利好 + 板块强 | 🟢 强势 | 60-100% | 激进布局抓主升 |
| 沪指 3800-4000 + 政策中性 + 板块中性 | 🟡 平淡 | 20-40% | 只做吸筹末期，控仓 |
| 沪指 < 3800 + 政策利空 + 板块弱 | 🔴 弱势 | 建议 ≤ 20% | 极谨慎，只做最强板块龙头 |
| 沪指 < 4000 + 国家政策强催化 | 🟡 政策驱动 | 30-50% | 政策受益板块可建仓 |
| 沪指 > 4000 + 高位滞涨 + 派发信号 | 🔴 顶部风险 | 减仓为主 | 警惕，宁错过不追高 |

**关键判定原则**：
- ❌ **不要写死"沪指 < 4000 = 0 新建仓"** = 是动态参考
- ✅ **沪指 < 4000** = 是"重要参考权重之一"，不是绝对条件
- ✅ **沪指 < 4000 但有强政策 + 板块集中** = 仍可建仓（仓位控制 30-50%）
- ✅ **沪指 > 4000 但高位滞涨** = 反而要警惕（不是"沪指过了 4000 就安全"）
- 创业板 vs 沪指：谁强说明资金进哪边（板块联动的微观验证）

### 2.4 沪指位置在 30 日区间的分位（辅助参考）
- 当前位置 < 30% = 低位（适合建仓）
- 当前位置 > 70% = 高位（警惕）
- 中位 = 震荡，多维综合判定

### 2.5 反例（不要犯的死条件错误）

❌ 死条件思维：
- "沪指 3950 < 4000 = 不能买任何票"
- "沪指 4050 > 4000 = 全力进攻"

✅ 动态思维：
- "沪指 3950，但政策强 + 板块强 = 仍可做板块龙头"
- "沪指 4050，但高位滞涨 + 派发 = 反而减仓"

## 3. Layer 2：板块过滤

### 3.1 资金流入 TOP3 板块
- 数据源：东方财富 / 同花顺板块资金流
- 主力净流入 > 1 亿 = 🟢 资金关注
- 主力净流入 < 0 = 🔴 排除整个板块

### 3.2 政策催化
- 国家七部委 / 发改委级别 = 🟢 强催化
- 行业协会 / 地方政府 = 🟡 中等
- 无政策 = 🟠 纯资金驱动（需主力资金支撑）

### 3.3 板块联动强度
- 板块内 ≥ 3 只标的同步启动 = 🟢 真联动
- 仅 1 只异动 = 🟡 可能是个股行为，非板块机会

## 4. Layer 3：K8 v2 6 项硬检查（重要参考，可结合市况调整）

> **K8 是"重要参考"，不是"绝对条件"。**
> **在强政策 + 板块集中 + 主力流入背景下，可适度放宽（但必须有强理由）。**

| # | 项 | 阈值 | 不通过的影响 |
|---|---|---|---|
| ① | **沪指 ≥ 4000** | 动态参考 | 沪指 < 4000 = 降权（结合市况可放宽） |
| ② | **5 日涨幅 ≤ 30%** | 防止超买 | > 30% = 已拉升期 = 错过买点（这条较硬） |
| ③ | **主力净流入 ≥ 1 亿** | 资金推动 | < 1 亿 = 无主力关注（这条较硬） |
| ④ | **止损位明确 ≤ -8%** | C3 红线 | 无法计算止损 = 排除（这条硬） |
| ⑤ | **盈亏比 ≥ 3:1** | 风险收益 | < 3:1 = 不值得（这条硬） |
| ⑥ | **缩量回踩验证** | B68 需求测试 | 缩量回踩 = 主力未出货（这条较硬） |

**关键**：
- 第 ⑤ 项盈亏比 = `(目标价 - 买入价) / (买入价 - 止损价) ≥ 3`
- ①②③⑥ = 较硬（市况极端时可放宽 ①）
- ④⑤ = 最硬（风控底线，不能破）
- 任何"硬"项 ❌ = 立即排除
- 任何"较硬"项 ❌ + 市况不允许 = 排除
- 任何"较硬"项 ❌ + 强政策/板块支撑 = 降权但可考虑

## 5. Layer 4：5 维评分（V4.3 v2 · 满分 5 分）

每只候选标必走 5 维，每维 0-5 分，加权后总分 0-5 分。

### 5.1 板块维度（权重 1.0）

| 分数 | 标准 |
|---|---|
| 5 | 主流资金流入 TOP3 + 国家政策催化 + 板块 ≥ 3 只同步 |
| 4 | 资金流入 TOP5 + 行业政策 + 板块 ≥ 2 只同步 |
| 3 | 资金流入 TOP10 或 仅政策催化 |
| 2 | 资金中性，无政策 |
| 0-1 | 资金流出或政策利空 |

### 5.2 趋势维度（权重 1.0）

| 分数 | 标准 |
|---|---|
| 5 | 30 日趋势上涨 + 当前在 30 日区间 < 30% 分位（低位启动）|
| 4 | 30 日趋势上涨 + 当前在 30 日区间 30-50% 分位 |
| 3 | 30 日震荡，方向不明 |
| 2 | 30 日趋势下跌但有止跌信号 |
| 0-1 | 30 日趋势下跌且无止跌 |

**关键指标**：
- 5 日累计涨幅 < 15% = 健康
- 5 日累计涨幅 15-30% = 警惕
- 5 日累计涨幅 > 30% = 已拉升期（K8 第 ② 项会卡掉）

### 5.3 量价维度（权重 1.2 · 最重要）

| 分数 | 标准 |
|---|---|
| 5 | 缩量回踩 + 主力净流入 + 量比 0.8-1.5 + B68 需求测试通过 |
| 4 | 量价配合 + 主力净流入 + 量比正常 |
| 3 | 量价中性 |
| 2 | 量价背离（价涨量缩 / 价跌量增）|
| 0-1 | 巨量长上影 / 高位放量滞涨 |

**核心参考框架**（量价 7 句 = **框架性参考，不是死规则**）：

> **实战中必须根据当下市况、个股阶段、板块背景灵活解读。**
> 同一句口诀在不同市况下含义不同：
> - "高位放量"：牛市 = 健康突破 / 熊市 = 派发
> - "量价背离"：牛熊初期 = 警示信号 / 末期 = 见顶
> - "缩量回踩"：强势股 = 主力锁仓 / 弱势股 = 无承接
> 框架是参考，**市况是上下文，个股是特例**。

1. 高位放量 → 牛市 = 健康突破 / 熊市或高位滞涨 = 派发嫌疑
2. 高位缩量 → 拉升末期 = 拉高出货 / 启动初期 = 主力锁筹待突破
3. 低位放量 → 吸筹可能 / 但要结合主力资金判断是否对倒
4. 低位缩量 → 等待 / 但要区分是"无承接"还是"主力锁筹"
5. 上涨缩量 → 警惕 / 但强势股启动初期可能是"轻松上涨"
6. 下跌缩量 → 可能是止跌 / 但要区分是"惜售"还是"无人接盘"
7. 量价背离 → 警示信号 / 但牛熊不同阶段含义不同

**关键原则**：
- ❌ **不要死记"高位放量 = 派发"** = 框架参考，要看市况
- ✅ **实战中 = 框架 + 市况 + 个股阶段 + 板块背景 + 主力意图 = 5 维综合**
- ✅ **同一句口诀在不同市况下解读可能完全相反**
- 量价是必要条件，不是充分条件（必须配合其他维度验证）

### 5.4 形态维度（权重 1.0）

**关键判定：当前在哪个威科夫阶段？**

| 威科夫阶段 | 形态特征 | 操作 |
|---|---|---|
| **吸筹期（A-B）** | 横盘 + Spring 出现 | 观察 |
| **吸筹末期（C-D）** | LPS（最后支撑点）缩量不破低 | **建仓点** ✅ |
| **拉升期（D-E）** | 放量突破吸筹区上沿 + 趋势上涨 | 持有（已涨过的不是买点）|
| **派发期（E-A）** | UT + UTAD + 高位放量滞涨 | **一票否决** ❌ |
| 下跌期（B-C） | 量增价跌 | 空仓 |

**关键形态识别**：
- Spring：跌破前低支撑 → 快速 V 反弹 + 放量 = 主力故意砸破吸筹
- ST（二次测试）：Spring 后再次回踩 + **缩量 + 不破 Spring 低点** = 吸筹确认
- LPS（最后支撑点）：吸筹末期小幅回调 + 缩量 + 价不跌 = **最佳建仓点**
- UT：突破前高 → 快速回落 + 放量 = 派发开始
- UTAD：UT 后再次回抽前高 + 缩量不破前高 = 派发确认
- LPSY：派发末期小幅反弹 + 缩量 + 价不涨 = 最后卖出机会

### 5.5 风控维度（权重 0.8）

| 分数 | 标准 |
|---|---|
| 5 | 止损 ≤ -5% + 盈亏比 ≥ 5:1 + 单票仓位可 ≤ 10% |
| 4 | 止损 ≤ -8% + 盈亏比 ≥ 3:1 + 单票仓位可 ≤ 20% |
| 3 | 止损 -8% 至 -10% + 盈亏比 2:1-3:1 |
| 2 | 止损 > -10% 或 盈亏比 < 2:1 |
| 0-1 | 止损无法计算 或 盈亏比 < 1:1 |

**注意**：本维度权重 0.8（低于其他） = 因为如果风控不合格，前面的形态/量价再好也不碰（已在 K8 第 ④ ⑤ 项卡过）。

### 5.6 评分汇总
```
总分 = (板块×1.0 + 趋势×1.0 + 量价×1.2 + 形态×1.0 + 风控×0.8) / 5
```

**决策阈值**：
- 总分 **≥ 4.0** = 🟢 候选
- 总分 **3.0-3.9** = 🟡 观察
- 总分 **< 3.0** = 🔴 排除

## 7. Layer 6：派发期一票否决（**最高优先级 · 唯一绝对条件**）

> **这是整个方法论中唯一绝对的"死条件"——其他都是参考权重，但派发期一旦判定 = 立即排除。**
> **为什么？因为派发期 = 主力已经在卖货 = 散户接盘 = 必亏。**

**核心规则：任何工具判定为派发期 → 整体拒绝，不与其他信号平级。**

```
├─ 量价分析 → 派发信号 +1
├─ K线形态 → 派发信号 +1
├─ 威科夫   → 派发信号 +1
├─ 主力资金 → 派发信号 +1
└─ 只要任一工具明确判定"派发期" → 一票否决
```

**派发期识别清单**（任一命中 = 派发）：
- [ ] 高位放量滞涨（涨幅 > 5%，但量比 > 2.0，长上影）
- [ ] UT 出现（突破前高后快速回落 + 放量）
- [ ] UTAD 通过（UT 后再次回抽前高 + 缩量不破前高）
- [ ] 主力资金 5 日累计净流出 > 10%
- [ ] 利好消息出现但股价不涨（量价背离）
- [ ] 北向资金持续卖出
- [ ] 换手率突增 > 5%（高位对倒嫌疑）

**为什么一票否决？**
- 利好消息容易压过技术性 🔴 信号（亨通惨案：310 亿订单 + AI 龙头光环 = 主力借利好出货）
- 派发期识别错误 = 100% 亏损
- 错过 1 只派发期票 ≠ 错过 1 只吸筹末期票（前者必亏，后者可补）

## 8. Layer 7：K168 三维分析（宏观-中观-微观）

**核心：避免单维分析被主力/环境带着走。3 维矛盾 = 警惕。**

### 8.1 三维定义

| 维度 | 范围 | 数据源 |
|---|---|---|
| 🔵 **宏观** | 年K/季K/月K/周K + 宏观经济 + 政策周期 + 大盘 + 板块联动 | 沪指 + 政策 + 行业指数 |
| 🟡 **中观** | 日K + 3日/5日/10日 + 量价时空 + 标的本身 + 板块内对比 + 技术形态 + 主力 | 标的日K + 板块对比 |
| 🟢 **微观** | 分时图 + 5分钟/1分钟K线 + 盘口 + 集合竞价 + 开盘 30 分钟 + 资金流 | 实时分时 + Tick |

### 8.2 3 维交叉验证矩阵

**任意 2 维矛盾 = 警惕；3 维矛盾 = 警惕 + 降权。**

| 场景 | 微观 | 中观 | 宏观 | 判定 |
|---|---|---|---|---|
| 建仓 | 集合竞价 + 开盘 30 分钟买盘涌入 | 日K 缩量回踩 | 行业顺风 + 大盘支撑 | 🟢 强信号 |
| 减仓 | 分时放量滞涨 | 日K 高位放量 | 大盘顶部 + 政策转向 | 🔴 强信号 |
| 持有 | 分时震荡 + 主力观望 | 日K 中继 | 行业持续 + 大盘震荡 | 🟢 持有 |

### 8.3 同构性原则（重要）

> **同一个形态/主力行为模式，在不同时间维度上呈现神似的表达。**

例如：
- 微观：9:31 砸 60.13 = 派发期 1
- 中观：单日跌 5% = 派发期 1
- 宏观：周线/月线大阴线 = 派发期 1

**3 维同构 = 强信号；3 维异构 = 警惕。**

### 8.4 维度跃迁触发器

任一触发 → 跃迁其他 2 维验证：
1. 微观信号 → 跃迁中观（日K 验证）
2. 中观信号 → 跃迁宏观（周K/月K 验证）
3. 宏观信号 → 跃迁中观（板块影响验证）
4. 数据矛盾 → 跃迁找根因
5. 新信息 → 跃迁所有维度

## 13. 关键心法（14 条）

1. **吸筹末期是唯一进场点**，其他阶段都错过最佳买点
2. **派发期一票否决**（唯一绝对条件），任何利好都不能压过派发信号
3. **沪指 4000 红线 = 动态参考线**，不是死条件（要结合政策 + 板块 + 量能综合判断）
4. **量价背离 = 见顶信号**（高位必警惕）
5. **利好消息 + 量价背离 = 主力借利好出货**（亨通惨案）
6. **创业板只分析不买入**（资金门槛 + 风险）
7. **历史新高无参照系**（无法算止损）
8. **止损位必须明确**（无法算 = 排除）
9. **盈亏比 ≥ 3:1**（风险收益不对等 = 不值得）
10. **3 维矛盾 = 警惕**（单维信号 = 不可信）
11. **派发期信号 vs 利好消息 → 信派发**（亨通惨案）
12. **每把工具学"能赚"+"会亏"**（不片面学）
13. **每日复盘 + 失职根因分析**（K111 闭环）
14. **任何工具/红线 = 参考权重**，市况是上下文，**不要写死**（K22 工具不是枷锁）⭐

## 18. 元规则（信号打架时优先级）

```
最高：实时价格走势（正在发生什么）
  ↑   主力资金动向（钱在往哪流）
  ↑   政策/消息面（为什么在动）
  ↑   技术形态（看起来像什么）
最低：历史对比（上次这样之后发生了什么）
```

**冲突处理**：
- 技术形态 vs 主力资金 → 信资金
- 政策 vs 走势 → 看政策级别（国家 = 信政策 / 行业 = 信走势）
- 历史 vs 走势 → 信走势
- 用户想法 vs 数据 → 提数据但不犟
