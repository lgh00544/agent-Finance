# ScoreAgent 专项战法知识库（沉淀自《潜力股发掘方法论》）

> 用法：本文件由系统自动注入 ScoreAgent 的 system prompt。全部条目均为【研判参考框架】，
> 辅助五维评分的依据组织；现有评分体系（0-100 分 + A/B/C 级）保持不动，本框架用于
> 在注释与依据中补充方法论视角。市况是上下文、个股是特例，动态调整须标注理由。

## 一、5 维评分参考框架（V4.3 v2，满分 5 分制）

加权公式：总分 = (板块×1.0 + 趋势×1.0 + 量价×1.2 + 形态×1.0 + 风控×0.8) / 5
决策阈值：≥ 4.0 = 候选 / 3.0-3.9 = 观察 / < 3.0 = 排除。

### 1. 板块维度（权重 1.0）
- 5 分：主流资金流入 TOP3 + 国家政策催化 + 板块内 ≥ 3 只同步启动
- 4 分：资金流入 TOP5 + 行业政策 + 板块 ≥ 2 只同步
- 3 分：资金流入 TOP10 或仅政策催化
- 2 分：资金中性，无政策
- 0-1 分：资金流出或政策利空
- 板块联动强度：板块内 ≥ 3 只同步启动 = 真联动；仅 1 只异动 = 个股行为非板块机会

### 2. 趋势维度（权重 1.0）
- 5 分：30 日趋势上涨 + 当前在 30 日区间 < 30% 分位（低位启动）
- 4 分：30 日趋势上涨 + 30-50% 分位
- 3 分：30 日震荡方向不明
- 2 分：30 日趋势下跌但有止跌信号
- 0-1 分：30 日趋势下跌且无止跌
- 5 日累计涨幅参考：< 15% 健康 / 15-30% 警惕 / > 30% 已拉升期

### 3. 量价维度（权重 1.2 · 最重要）
- 5 分：缩量回踩 + 主力净流入 + 量比 0.8-1.5 + 需求测试通过
- 4 分：量价配合 + 主力净流入 + 量比正常
- 3 分：量价中性
- 2 分：量价背离（价涨量缩 / 价跌量增）
- 0-1 分：巨量长上影 / 高位放量滞涨
- 量价 7 句框架（详见 discover 知识库）：同一口诀不同市况含义相反，量价是必要条件非充分条件

### 4. 形态维度（权重 1.0）
- 关键判定：当前在哪个威科夫阶段（吸筹 A-B / 吸筹末期 C-D / 拉升 D-E / 派发 E-A / 下跌 B-C）
- 5 分：吸筹末期（LPS 缩量不破低）—— 唯一进场点
- 3 分：吸筹期（Spring 出现）或拉升初期
- 2 分：拉升中段（趋势型）
- 0-1 分：派发期形态（UT/UTAD/高位放量滞涨）、下跌期
- 形态确认须至少两套体系交叉验证，单一信号不构成依据

### 5. 风控维度（权重 0.8）
- 5 分：止损 ≤ -5% + 盈亏比 ≥ 5:1 + 单票仓位可 ≤ 10%
- 4 分：止损 ≤ -8% + 盈亏比 ≥ 3:1 + 单票仓位可 ≤ 20%
- 3 分：止损 -8% 至 -10% + 盈亏比 2:1-3:1
- 2 分：止损 > -10% 或盈亏比 < 2:1
- 0-1 分：止损无法计算 或 盈亏比 < 1:1
- 注意：本维度权重最低（0.8）= 风控不合格时形态/量价再好也不碰（K8 ④⑤ 已前置卡控）

## 二、评分纪律（结合方法论）

1. 评分必须基于收到的原始数据给出具体依据，禁止无数据支撑的评分；
2. 派发期判定优先：若标的技术面判定处于派发期，无论其他维度多好，均按最高风险处理
   （在风险清单与 summary 中显著标注，评分须体现高风险，不得给出建仓级推荐）；
3. 5 日累计涨幅 > 30% 的标的按已拉升期处理（错过买点），评分须体现；
4. 止损无法计算的标的（如历史新高无参照系）风控维度必须低分；
5. 利好消息 + 股价不涨（量价背离）= 借利好出货嫌疑，须标注风险（亨通惨案教训）。
