# 市况判定专项战法知识库（沉淀自《潜力股发掘方法论》）

> 用法：本文件由系统自动注入市况评分 Agent 的 system prompt。现有五维 0-50 打分机制保持不动，
> 本知识库提供方法论视角的市况综合判定框架，用于五维打分的依据组织与 summary 结论表达。
> 全部条目均为【动态参考】，不是死条件；调整必须在输出中标注理由。

## 一、市况判定核心理念

> 沪指 4000 红线 = 动态参考线，不是硬性一票否决。
> 任何框架/工具/红线 = 都是参考权重，不是绝对条件。
> 市况判断 = 多维综合，不是单数字决定。

为什么不是死条件：
- 沪指 < 4000 时，可能有强政策驱动（如国家级利好）= 可以建仓
- 沪指 > 4000 时，可能是高位滞涨 + 派发期 = 反而要减仓
- 沪指 3800 但创业板强 + 板块集中 = 仍然有结构性机会

## 二、市况多维综合判定（7 维度）

| 维度 | 数据 | 判定信号 |
|---|---|---|
| 沪指位置 | 实时点数 | 在 30 日区间分位（<30% 低位适合建仓 / >70% 高位警惕） |
| 沪指趋势 | 5 日/10 日方向 | 上涨/下跌/震荡 |
| 创业板强弱 | 创业板 vs 沪指 | 资金进成长还是避险（谁强 = 资金进哪边） |
| 北向资金 | 净流入/流出 | 外资态度 |
| 板块联动 | TOP3 板块资金流 | 主力方向 |
| 政策环境 | 国家级/行业级 | 政策驱动 vs 无政策 |
| 量能配合 | 今日/30 日均量 | 放量/缩量 |

## 三、综合市况 5 档（7 维 + 政策 + 板块综合）

| 沪指 + 政策 + 板块 | 市况 | 仓位建议 | 选股策略 |
|---|---|---|---|
| 沪指 ≥ 4000 + 政策利好 + 板块强 | 强势 | 60-100% | 激进布局抓主升 |
| 沪指 3800-4000 + 政策中性 + 板块中性 | 平淡 | 20-40% | 只做吸筹末期，控仓 |
| 沪指 < 3800 + 政策利空 + 板块弱 | 弱势 | ≤ 20% | 极谨慎，只做最强板块龙头 |
| 沪指 < 4000 + 国家政策强催化 | 政策驱动 | 30-50% | 政策受益板块可建仓 |
| 沪指 > 4000 + 高位滞涨 + 派发信号 | 顶部风险 | 减仓为主 | 警惕，宁错过不追高 |

## 四、政策催化分级

- 国家部委 / 发改委级别 = 强催化
- 行业协会 / 地方政府 = 中等
- 无政策 = 纯资金驱动（需主力资金支撑）

## 五、判定纪律

1. 不要写死「沪指 < 4000 = 0 新建仓」（是动态参考）；沪指 < 4000 但有强政策 + 板块集中 = 仍可建仓（仓位控制 30-50%）；沪指 > 4000 但高位滞涨 = 反而警惕；
2. 7 维中 ≥ 5 维偏弱 → 谨慎（仓位 ≤ 20%）；≥ 5 维偏强 → 可建仓（仓位按评分定）；
3. 只依据提供的数据打分，不得臆测缺失维度；数据不可用时给保守中间分并在 summary 中说明；
4. 评分结果直接决定当日候选池规模（分越低候选越少），请严格客观。
