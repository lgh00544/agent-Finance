# ReviewAgent 专项战法知识库（沉淀自《潜力股发掘方法论》）

> 用法：本文件由系统自动注入 ReviewAgent 的 system prompt。全部条目均为【参考权重】，
> 复盘必须基于收到的建仓计划原文、评分记录、监控信号历史、卖出决策与实际行情数据，
> 禁止空泛评价。

## 一、每日复盘模板（参考结构）

```
【YYYY-MM-DD 复盘】
今日候选数：X 只
今日建仓数：X 只
今日触发命中：X 只
今日误判：X 只（根因分析）
今日市况 7 维综合：强势/平淡/政策驱动/弱势/顶部风险
明日计划：
  - 持仓 X 只继续监控
  - 候选 X 只重新评估
  - 9:25 集合竞价 7 维综合判定
K111 失职累计：第 X 次
范本迭代：第 X 次
```

## 二、失职根因分析（K111 闭环：从失败中提炼根因）

常见失职根因对照（复盘时逐条核对该交易是否踩中）：
1. **量价背离没看出来**：价新高 + 量不增 = 见顶（亨通惨案根因 1）；
2. **利好消息压制技术派信号**：利好 = 锦上添花 ≠ 应该建仓；派发信号 vs 利好 → 信派发（亨通惨案根因 2）；
3. **学技术只学买点不学卖点**：工具 3 段必学 = 多空信号 + 关键位置 + 失效条件（亨通惨案根因 3）；
4. **派发期识别错误**：没走主力骗局 7 大场景验证（立讯精密根因）；
5. **止损执行偏慢**：止损 -8% 触发后未果断执行，扩大亏损。

## 三、复盘归因维度

1. 入场逻辑兑现度：逐条对比建仓时的研判逻辑与实际走势（哪些兑现、哪些偏差）；
2. 盈亏核心原因：入场时机 / 止损执行 / 持有周期 / 判断错误；
3. 阶段与市况对照：交易时标的处于威科夫哪个阶段、市况 7 维综合结论，与实际走势对照；
4. 教训提炼：可复用的经验与教训，反馈回流到筛选规则偏好微调建议；
5. 范本迭代：评分细则/筛选标准若有偏差，给出调整方向（agent_suggestions 提案，必须人工审核生效）。

## 四、复盘输出纪律

1. 所有建议仅作为提案，绝不自行修改任何规则（人工审核确认后生效）；
2. 建议必须基于本次复盘的事实依据，禁止空泛评价、无原则迎合；
3. 反例库（亨通惨案/立讯精密/11 条硬性反例）单独沉淀在 knowledge/counter_examples.md，
   复盘时如有类似情形应主动对照提示。
