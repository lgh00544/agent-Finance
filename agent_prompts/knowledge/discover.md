# DiscoverAgent 专项战法知识库（沉淀自《潜力股发掘方法论》）

> 用法：本文件由系统自动注入 DiscoverAgent 的 system prompt。全部条目均为【参考权重】，
> 不是死条件；市况是上下文、个股是特例，动态调整必须在输出中标注理由。

## 一、选股漏斗（7 层过滤 SOP）

```
[Layer 1] 市况过滤（7 维动态综合）→ 沪指只是参考之一
[Layer 2] 板块过滤 → 主流资金流入板块
[Layer 3] K8 v2 6 项硬检查 → 1 项不过 = 重要参考（可结合市况适度放宽）
[Layer 4] 5 维评分（0-5 分制）→ 评分 < 4.0 = 排除
[Layer 5] K16 11 项失效 → 警 ≥ 5 项 = 排除
[Layer 6] 派发期最高风险原则 → 派发信号 = 默认排除（最高优先级）
[Layer 7] K168 三维验证 → 3 维矛盾 = 警惕
[输出]   决策：候选 / 观察 / 排除
```

漏斗关键原则：Layer 1-5 为参考权重（可结合市况调整）；Layer 6 派发期为最高优先级风险原则；
前面任何一层不通过 = 重要警示，不一定要立即排除，但须大幅降权并在输出中说明。

## 二、Layer 3：K8 6 项硬检查（重要参考，可结合市况调整）

| # | 项 | 阈值 | 不通过的影响 |
|---|---|---|---|
| ① | 沪指 ≥ 4000 | 动态参考线 | 沪指 < 4000 = 降权（结合市况可放宽） |
| ② | 5 日涨幅 ≤ 30% | 防止超买 | > 30% = 已拉升期 = 错过买点（较硬） |
| ③ | 主力净流入 ≥ 1 亿 | 资金推动 | < 1 亿 = 无主力关注（较硬） |
| ④ | 止损位明确 ≤ -8% | C3 红线 | 无法计算止损 = 排除（硬） |
| ⑤ | 盈亏比 ≥ 3:1 | 风险收益 | (目标价-买入价)/(买入价-止损价) < 3 = 不值得（硬） |
| ⑥ | 缩量回踩验证 | 需求测试 | 缩量回踩 = 主力未出货（较硬） |

优先级：④⑤ 最硬（风控底线，不能破）；①②③⑥ 较硬（市况极端时可放宽 ①）。
任何「硬」项不过 = 排除；「较硬」项不过 + 市况不允许 = 排除；「较硬」项不过 + 强政策/板块支撑 = 降权但可考虑。

## 三、Layer 5：K16 11 项失效检查（防假信号）

| # | 项 | 警 = |
|---|---|---|
| K16-1 | 位置（顶/底/中） | 位置不对，反转形态失效 |
| K16-2 | 量能 ≥ 1.5 倍均量 | 无量 = 纸上画饼 |

## 四、威科夫 5 阶段定位与关键形态

| 阶段 | 形态特征 | 操作 |
|---|---|---|
| 吸筹期（A-B） | 横盘 + Spring 出现 | 观察 |
| 吸筹末期（C-D） | LPS（最后支撑点）缩量不破低 | 建仓点（唯一进场点） |
| 拉升期（D-E） | 放量突破吸筹区上沿 + 趋势上涨 | 持有（已涨过的不是买点） |
| 派发期（E-A） | UT + UTAD + 高位放量滞涨 | 最高风险（默认排除） |
| 下跌期（B-C） | 量增价跌 | 空仓 |

关键形态识别：Spring（跌破前低 → 快速 V 反弹 + 放量 = 主力故意砸破吸筹）；
ST 二次测试（Spring 后回踩 + 缩量 + 不破 Spring 低点 = 吸筹确认）；
LPS（吸筹末期小幅回调 + 缩量 + 价不跌 = 最佳建仓点）；
UT（突破前高 → 快速回落 + 放量 = 派发开始）；UTAD（UT 后回抽前高 + 缩量不破前高 = 派发确认）；
LPSY（派发末期小幅反弹 + 缩量 + 价不涨 = 最后卖出机会）。

## 五、量价 7 句（框架性参考，不是死规则）

1. 高位放量 → 牛市 = 健康突破 / 熊市或高位滞涨 = 派发嫌疑
2. 高位缩量 → 拉升末期 = 拉高出货 / 启动初期 = 主力锁筹待突破
3. 低位放量 → 吸筹可能 / 结合主力资金判断是否对倒
4. 低位缩量 → 等待 / 区分「无承接」还是「主力锁筹」
5. 上涨缩量 → 警惕 / 强势股启动初期可能是「轻松上涨」
6. 下跌缩量 → 可能止跌 / 区分「惜售」还是「无人接盘」
7. 量价背离 → 警示信号 / 牛熊不同阶段含义不同

同一句口诀在不同市况下解读可能完全相反：量价是必要条件不是充分条件，必须配合其他维度验证。

## 七、Layer 4 5 维评分（0-5 分制，作为研判参考框架）

评分公式：总分 = (板块×1.0 + 趋势×1.0 + 量价×1.2 + 形态×1.0 + 风控×0.8) / 5
决策阈值：≥ 4.0 = 候选 / 3.0-3.9 = 观察 / < 3.0 = 排除。
5 维 0-5 分细则（每维最高分标准）：
- 板块（1.0）：主流资金流入 TOP3 + 国家政策催化 + 板块 ≥ 3 只同步 = 5
- 趋势（1.0）：30 日趋势上涨 + 当前在 30 日区间 < 30% 分位（低位启动）= 5
- 量价（1.2，最重要）：缩量回踩 + 主力净流入 + 量比 0.8-1.5 + 需求测试通过 = 5
- 形态（1.0）：当前处于吸筹末期（LPS 缩量不破低）= 5（派发期 = 0-1）
- 风控（0.8）：止损 ≤ -5% + 盈亏比 ≥ 5:1 + 单票仓位 ≤ 10% = 5
