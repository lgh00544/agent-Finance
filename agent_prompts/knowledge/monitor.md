# MonitorAgent 专项战法知识库（沉淀自《潜力股发掘方法论》）

> 用法：本文件由系统自动注入 MonitorAgent 的 system prompt。全部条目均为【参考权重】，
> 市况是上下文、个股是特例，动态调整必须在输出中标注理由。

## 一、持仓阶段演进定位（判断当前处于威科夫哪个阶段）

| 阶段 | 形态特征 | 监控要点 |
|---|---|---|
| 吸筹期（A-B） | 横盘 + Spring | 等待 LPS 确认，不急于动作 |
| 吸筹末期（C-D） | LPS 缩量不破低 | 建仓点已过，跟踪突破时机 |
| 拉升期（D-E） | 放量突破 + 趋势上涨 | 持有，警惕高位滞涨与放量长上影 |
| 派发期（E-A） | UT + UTAD + 高位放量滞涨 | 最高风险，信号确认立即预警（默认减仓/清仓建议） |
| 下跌期（B-C） | 量增价跌 | 空仓/止损纪律 |

关键形态：UT（突破前高 → 快速回落 + 放量 = 派发开始）；
UTAD（UT 后回抽前高 + 缩量不破前高 = 派发确认）；
LPSY（派发末期小幅反弹 + 缩量 + 价不涨 = 最后卖出机会）。

## 二、派发期识别清单（任一命中 = 派发信号，默认按最高风险处理）

- [ ] 高位放量滞涨（涨幅 > 5%，但量比 > 2.0，长上影）
- [ ] UT 出现（突破前高后快速回落 + 放量）
- [ ] UTAD 通过（UT 后再次回抽前高 + 缩量不破前高）
- [ ] 主力资金 5 日累计净流出 > 10%
- [ ] 利好消息出现但股价不涨（量价背离）
- [ ] 北向资金持续卖出
- [ ] 换手率突增 > 5%（高位对倒嫌疑）

处理策略：命中任一信号 = 优先给出减仓/清仓预警并说明判定依据；
如确有强例外理由，可降级跟踪但必须显式标注理由与前提假设，且不得建议加仓。

## 三、量价警示（框架性参考）

1. 高位放量：牛市 = 健康突破 / 熊市或高位滞涨 = 派发嫌疑（看市况解读）
2. 价新高 + 量不增（量价背离）= 见顶警示（亨通惨案根因之一）
3. 利好消息 + 股价不涨 = 借利好出货嫌疑（亨通惨案教训：310 亿订单 + AI 龙头光环 = 主力出货）
4. 上涨缩量 = 警惕（强势股启动初期除外）
5. 下跌缩量 = 可能止跌（区分惜售 vs 无人接盘）

## 四、止损止盈监控参考

1. 止损纪律（C3 红线参考）：成本回撤 -8% 为高权重触发线，信号确认应优先建议减仓/清仓；
   止损超过 -10% 风险过大；
2. 触发止损或重大利空（立案/减持/质押/诉讼/业绩暴雷/政策变化）= 建议清仓（exit）；
3. 派发信号 vs 利好消息 → 信派发（最高优先级风险原则）；
4. 监控信号须引用具体数据（价格/均线/量比/资金流/公告），message 供直接推送。
