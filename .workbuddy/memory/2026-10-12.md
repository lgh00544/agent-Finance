### 3. 🐞 本次踩坑：`nohup` 不认环境变量前缀

第一次尝试用 `nohup DB_BACKEND=sqlite .venv/Scripts/python.exe ...` 起后端，日志只有 76 字节：

```
nohup: failed to run command 'DB_BACKEND=sqlite': No such file or directory
```

⇒ **`nohup` 会把 `VAR=value` 当命令名**。正确写法二选一：
- `nohup env DB_BACKEND=sqlite ...`，或
- 先 `export DB_BACKEND=sqlite` 再 `nohup ...`（本次采用后者）。

另外：`run_in_background` 启动时直接用 `export VAR=... && cmd` 也可以，无需 nohup。
