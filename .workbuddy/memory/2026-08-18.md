## candidates 页黑屏根因定位（17:50，`.map is not a function`）

- 性能优化后 DCL 1.7s 但 candidates 页仍黑屏，Console 报 `TypeError: .map is not a function at CandidatesPage.tsx:162:19`
- **根因**：后端 `/candidates/dates` 路由返回 `{"dates":[...]}`（包裹对象），前端 `candidateDates()` 期望 `string[]`（裸数组）。`dates` 是 truthy 对象 → `(dates ?? []).map()` 的 `??` 不触发 → `.map()` 调在普通对象上 → 崩溃
- curl 实证：`/api/candidates/dates` → `{"dates":["2026-08-18",...]}`（包裹）；`/api/candidates` → `[{...}]`（裸数组）；`/api/track/verify/dates` → `["2026-08-17",...]`（裸数组）。`/candidates/dates` 是唯一包裹数组的端点
- 此 bug 一直存在，被 49s 超时掩盖（页面从未渲染到这步）。性能修复后才暴露
- 之前 summary 中"candidateConcentration API 路径 404"是误判：后端路由和前端调用都是单数 `/candidate/concentration`，路径匹配，无 404
- **修复方案**：后端 routes.py 改 1 行 `return repo.list_candidate_dates(limit)` + 前端 candidateDates 加 Array.isArray 防御
- 提交：0c4989f（fix: 候选/市场研判日期接口返回裸数组（修复 React SPA 黑屏））
