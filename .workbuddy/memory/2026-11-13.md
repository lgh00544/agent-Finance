真实报错形态（不是 schema 字段缺失，是 **JSON 结构错位**）：

```
Invalid JSON: expected `,` or `]` at line 1 column 2343
[type=json_invalid, input_value='{"action": "reduce", "se..."止损参考": 71.47}}']
```

注意 column 2343 —— 远低于 `llm_max_tokens=32768`，**不是 token 截断**。是模型在「应为数组」的位置吐了对象、提前闭了 `}`，解析器在数组上下文里撞到 `]` 期望值。`AuditOutput` 那边是 10-11 条 validation errors，形态不同（字段级）。

判定：**prompt/schema 契约与模型实际输出形态不匹配**，属真实缺陷，非上游故障。修复方向二选一（需 sir 拍板，涉及研判标准）：① 在 Pydantic 校验层做 dict→list 宽容归一；② 收紧 prompt 明确数组契约。①改动小但可能掩盖模型错误，②更正确但要动 prompt 基线。
