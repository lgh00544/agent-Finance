## 协作模式

- **🔴 第一硬规则：目标不打折扣地落地**（sir 2026-09-16）：功能范围／数据正确性／验收标准**一条不砍**；禁止"哪里都讲究一点"；遇阻**换方法不降目标**（分段落盘／分批交付，但每批标准与原目标完全一致，"切"≠"减"）；"先跑通再说"属降标准；省 token 只省表达形式，不省功能与验收项。冲突时以目标为先。
- **默认产出 = Claude Code 执行提示词**（2026-08-19）：只含需求＋规则＋约束，不含代码；sir 不必每次说。涉交易规则／研判标准／红线时，加一段"红线约束"。
- **🔴 任何回复末尾一律附「可复制提示词」**（sir 2026-09-16 追加）：**不止"提需求"时**——审核结论／核验汇报／状态同步／问题诊断／阶段收口，只要产出结论或下一步，**回复最后必须附一段连续可复制文本**（代码块包住）。理由：sir 是执行端调度者，拿到结论要能**立刻转发**，不该再问"给他什么"。**确无可执行动作时（纯等待态）也要给下一个动作的提示词**（如"次日触发后怎么核对"），不留空。执行端按实际写（DSH／Claude Code／Codex）。
- **sir 说"给提示词"**（2026-08-27）→ 只给**一段可复制文本** = ①执行文件的准确 path ＋ ②红线／约束／前提。不铺背景、不列表格、不写多段解读。
- 大需求（5+ 批次／多模块联动）→ 先写 `D:\self\{主题}_方案.md`，再出批次执行指令。
- 审核任务交付 → 必给"可复制给其他 agent 的总结段"（①问题 ②操作 ③文件路径）。
- 单人项目，**无工程师角色**（2026-08-24）→ 统一写"Claude Code / DSH 执行指令"，不用"交接工程师"格式。
- **自文件默认落 `D:\self\`**（2026-08-21）：提示词／方案／执行指令／审核结论／工单／风险清单，命名 `{主题}_{版本}_{文档类型}.md`。desktop `提示词\` 仅历史镜像，同名旧版加"已过期"banner（**不删除**）。
- **记忆自主维护授权**（2026-09-15）：sir 授权助手自行维护 `.workbuddy/memory/`（拆分／压缩／新增专项文件），**不必每次确认**；同时授权把执行端（Claude Code / Codex / DSH）需要的高频陷阱与环境说明同步进 `D:\self\AGENTS.md`。原则：`MEMORY.md` 保持索引级短小（防注入截断），细节下沉专项文件；`AGENTS.md` 只放执行端真正会踩的坑。
- **范围收窄**（sir 2026-09-17）：本会话**只跟踪「买卖点信号体系」**（批 1 收口 → 批 2 → 批 3）；因子体系 v7、同花顺模块下线、React v2 工单、评级重做等并行线**不由本会话跟**，由 sir 另行调度。批 1 收口 = 观察期 3 个交易日（09-17 / 18 / 21）逐日核对全过 → 由本会话主动出《批 1 收口验收报告》；**不收口不进批 2**。

## 前端规则

- **只改 React `web/src/`，不动 Streamlit**（2026-08-20）。例外仅三种：①后端 API 变更致旧版报错阻塞 ②sir 显式点名 ③React 侧未迁移。后端／数据／Agent／交易规则 → 只动后端。
- **任务看板 UI 范式**（2026-08-31）：命中「≥3 个明确流转阶段／表格多列表示状态／需一眼看到卡在哪个阶段」之一即推荐 → 5 列看板（列名＋计数）＋ 右侧 Drawer 720px 三段 ＋ `@dnd-kit` 拖拽（**必须 modal.confirm 二次确认**）＋ 顶部 `Input.Search`／`Select` 筛选 ＋ 复用已有 API（禁止为同一动作新加后端路由），改动 ≤250 行。

## 省 token 三层铁律

- **提示词端**：引用替代复述（`参见 §X`）／6 段结构（元信息·目标·架构约束·规则·执行顺序·红线）／禁代码块（改 `path:line` 引用）／表格列 ≤4／长度 简单≤80·中等≤150·复杂≤250·多批次≤400 行
- **执行端（Claude Code）**：不复读已固化信息／不写超范围代码／docstring ≤3 行且函数体内不写注释／复用已有函数／测试不超规定数量／报告 ≤10 行
- **会话级**：每批次独立会话／状态靠 memory 不靠对话历史／同会话禁止重复 Read 大文件（用 Grep 定位）
- **熔断**：单会话 >200K token 或 >30 轮 → 收尾 commit，开新会话
- **改动行数预算**：简单 ≤50／中等 ≤80／复杂 ≤150 行，超出停下报告 sir
- **不能省的**：§五红线、字段／阈值／触发条件、准确 `path:line`

## 设计哲学（sir 拍板）

LLM 出"艺术判断" → 代码层换算"可执行事实"（100 股整数倍／股数／金额）｜展示层只给最终可执行数字｜边界自动处理＋每节点留人工入口｜功能不成熟不展示

## 术语
