- 修复：`D:\self\backend\app\db\session.py:298-313` 在 `_ensure_user_columns` 加一段预清理 DELETE（MySQL 分支，SQLite 不动），先删 NULL 行中会与 user_id=1 冲突的子集，再回填

**已落地**：
1. `D:\self\backend\app\db\session.py` 修复迁移逻辑（15 行新增）
2. 多账号后端启动成功，飞书桥 `bridge_enabled=true, connected=true, admin_count=1`
3. 临时诊断脚本已清理（`_tmp_check_main.py` / `_tmp_pnl_check.py`）

- sir 提"多账号是默认主模式"——但当前 `.env` 是 `MULTI_USER_ENABLED` 未设（默认 false）+ mysql + memory + local qdrant 的混合配置，**不是真正多账号**。真正多账号需要 `MULTI_USER_ENABLED=true` + `CACHE_BACKEND=redis` + `QDRANT_MODE=server`（影响鉴权/缓存/前端），待 sir 拍板单独排期批次
