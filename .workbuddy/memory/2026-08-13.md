## 项目结构核心理解（备查）

### Agent 体系（8 业务 + 2 辅助）
| Agent | 职责 | 怎么做 |
|---|---|---|
| Discover | 每日潜力股挖掘 | 硬过滤(ST/停牌/成交额≥1亿→top300) → LLM初选(5-15只) → 新闻核实(向量检索top5) → LLM终选剔除利空 → 落库 |
| Score | 五维打分 A/B/C | 基本面30%/技术25%/资金15%/舆情15%/行业15%，0-100分。**权威评级来源，不兜底** |
| Position | 分批建仓方案 | 3-4档区间+资金配比+止损止盈，总仓≤60%/单票≤30%，仅B+以上可生成 |
| Monitor | 盘中持仓监控 | 每3分钟，实时行情60s缓存，输出 exit/reduce/hold+severity，飞书推送 |
| Sell | 卖出决策 | sell/partial/hold+置信度；游资撤离只触发partial，清仓须双条件 |
| Review | 卖出复盘 | 盈亏归因+教训+偏好回流+agent_suggestions（人工审核后生效） |
| MarketCondition | 市况评分(discover前置) | 五维0-10分，总分50，决定候选池规模上限 |
| MarketIntel | 市场研判底座(新落地) | 5维度：阶段定性/核心矛盾/风险偏好切换/量能信号/次日盯盘点，参考维度注入全部Agent |
| TrackVerify | 候选池T+N验证 | 客观统计胜率，提炼规则优化建议 |
| BatchChat | 候选池批量验证对话 | 只读分析+调整留痕，绝不自动改业务数据 |

### 职责分工
- **代码**：数据采集/硬过滤/数学计算/存储/缓存/调度/告警/任务队列/游资胜率统计/标签联动
- **LLM**：一切主观研判（趋势/估值/舆情/买卖时机/评分/卖出决策/复盘建议）
- **人工**：最终拍板（审核采纳建议、实际交易、维护偏好档案）

### 铁律
1. 代码/LLM 强分离；2. 评级权威单一化(score.grade不兜底)；3. 人工审核红线；4. 事实为先不编造；5. 调教集中在 agent_prompts/ + 偏好档案 + 知识库

### 关键路径
- 后端: backend/app/agents/、db/repo.py、api/routes.py、graph/graphs.py、datasource/akshare_source.py
- 前端: streamlit/pages/*.py、app.py
- 知识库: agent_prompts/ (global_base_prompt + knowledge/*.md + *_prompt.py)、base_file/（方法论/持仓/游资）
- 同步: sync_manager.py (check/init/backup/restore)，TiDB 云端 + SQLite 本地冷备
